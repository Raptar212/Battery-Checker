# План — Battery Checker

Правится по ходу работы. Протоколы устройств — `docs/PROTOCOLS.md`.

**Решение 2026-11-16:** свой код на **C# / .NET 10 WPF**. Интерфейс и поведение — по образцу
Bluetooth Battery Monitor Widget (Store); его код закрыт, поэтому берём только UX, без кода и
ассетов. Форк BlueGauge (Rust) отменён: апстрим не собирается с публичным `tray-icon`
(зависит от незамёрженного PR #302), а UI образца пользователю понятнее.

⚠️ Windows хранит **последний известный** заряд BT-устройства и после отключения
(AirBuds: 100 % при выключенных наушниках, PnP-статус узла `OK`) — связь читать отдельно.

## Этап 1 — первая версия (виджет + трей) — ветка `BC-1`, влито (PR #1), хвосты — в BC-4

Раскладка: `src/BattaryChecker/` (WPF, `net10.0-windows`), `tests/BattaryChecker.Tests/` (xUnit).

**Статус (2026-11-16):** пункты 2–8 в коде и проверены на железе (G602, A50, AirBuds,
DualSense по USB); 64 unit-теста; своя память release ≈ 60 МБ. До PR осталось:
- [ ] независимое ревью ветки (`HidChannel` и источники — зона риска);
- [ ] DualSense по Bluetooth — проверить пассивный режим;
- [ ] неделя работы без падений.

Отличия от исходного плана: BLE не делали (устройств нет); HID — через Win32, не WinRT и не
`HidSharp`; добавлены переименование устройств и «сон» 5 минут для мыши/геймпада.

1. **Каркас:** решение, проект, тесты; гейт `dotnet format --verify-no-changes &&
   dotnet build -warnaserror && dotnet test`.
2. **Модель:** `BatteryReading {Id, Name, Percent?, Charging, Connected, Source, UpdatedAt}`;
   источники — `IBatterySource.ReadAsync()`; общий опрос раз в 30 с.
3. **Источники:**
   - Bluetooth Classic — WinRT `DeviceInformation.FindAllAsync` со свойством `{104EA319-…} 2`;
   - BLE — GATT `0x180F`/`0x2A19`;
   - HID (P/Invoke `hid.dll` или `HidSharp`): Logitech HID++ 2.0, Astro A50, DualSense (пассивно).
   Парсеры ответов — чистые функции, unit-тесты на байтах из проб.
4. **Виджет:** тёмная «таблетка» со скруглением и
   цветной рамкой, поверх всех, свободно перетаскивается, позиция запоминается. По каждому
   подключённому устройству: иконка типа (мышь/гарнитура/геймпад/наушники) + батарейка с
   заливкой по цвету порога (зелёный/жёлтый/красный) + `NN%`; между устройствами — разделитель.
5. **Панель по клику на виджет** (**без вкладок**):
   шапка (название, «N подключено», обновить, закрыть); секция «Подключённые» — карточки:
   иконка типа в квадрате, имя, «Подключено · <канал>», батарейка, `NN%` цветом порога,
   «глаз» = скрыть; секция «Отключённые (N)» сворачивается, серые карточки
   «Отключено · последний уровень NN %» или «—». Тёмная тема, красный акцент.
6. **Трей:** иконка с минимальным зарядом, подсказка со списком, меню: показать/скрыть виджет,
   настройки, выход.
7. **Настройки (одно окно, без вкладок):** порог низкого заряда, уведомления, автозапуск,
   скрытые устройства. Хранятся в `%LOCALAPPDATA%\BattaryChecker\config.json`; битый файл не
   перезаписывается молча (урок бага BlueGauge №1).
8. **Уведомления:** низкий заряд с cooldown, полный заряд.

Критерий готовности: все 4 устройства в виджете и трее, неделя без падений, RAM ≲ 60 МБ,
сеть — ноль соединений.
